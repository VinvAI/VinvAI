# Pick your coding agent

Vinv never calls a model provider itself. All of its thinking — understanding your project, working out how services start, fixing what breaks — runs through a coding agent CLI you already have installed and pay for:

- Claude Code
- Cursor CLI
- Codex
- and others

Open **Configure**, pick the agent, and save. The panel tells you if the CLI isn't installed yet and can install it for you.

That's the last decision Vinv asks you to make. From here on, Auto-Pilot drives.
